已整理成稿

不是搬运，是把素材重新编辑成你的表达。

回声编辑部面向内容创作者，把短视频链接、本地 MP4 或手动文案接进同一条工作流：提取、转写、改写、配音、成片。

01 INPUT

输入

粘贴抖音链接，上传 MP4，或者直接粘贴原始文案。

02 TRANSCRIBE

转写

ASR（语音识别）把视频里的声音整理成逐字稿。

03 REWRITE

改写

AI 根据平台语气生成小红书或抖音精选文案。

04 VOICE

配音

TTS（文字转语音）把稿件变成中文旁白。

05 VIDEO

成片

ffmpeg 合成配图、音频和竖屏 MP4。

一个本地优先的内容工作间

回声编辑部默认在你的电脑上运行。它会调用 DeepSeek、Pexels、edge-tts 等外部服务，但生成的音频、视频和本地配置都留在你的机器上。

ASR Automatic Speech Recognition，语音识别：把视频声音转成文字。
TTS Text-to-Speech，文字转语音：把改写好的稿子生成配音。
CI Continuous Integration，持续集成：每次提交后自动检查代码有没有明显问题。
